# EMC License Generator

Приватная standalone-утилита разработчика для выпуска подписанных Ed25519-лицензий EMC Toolkit. Проект не требует npm-зависимостей и поддерживает Node.js 18 или новее.

## Установка

```sh
npm install
```

## Однократное создание ключей

На доверенном, желательно офлайн-компьютере выполните:

```sh
npm run generate:keypair
```

Команда создаёт `private-key.pem` и заменяет `public-key.pem`. Она откажется перезаписывать существующий private key. Файл `private-key.pem` **никогда нельзя коммитить, передавать пользователям или помещать в репозиторий EMC Toolkit**. Храните его в зашифрованном секретном хранилище с защищённой резервной копией.

После создания новой пары скопируйте напечатанное base64url-значение public key в `src/license/publicKey.js` EMC Toolkit и выпустите новую сборку приложения. Лицензии проверяются только той сборкой EMC Toolkit, чей `LICENSE_PUBLIC_KEY` соответствует `public-key.pem`, использованному с private key. Включённый в этот экспорт `public-key.pem` уже соответствует текущему ключу EMC Toolkit; для выпуска совместимых с текущими сборками лицензий нужен соответствующий существующий private key.

## Выпуск лицензий

Интерактивный запуск (значения по умолчанию — Pro и бессрочная лицензия):

```sh
npm run license
```

Бессрочная **Pro**-лицензия (`expiresAt: null`):

```sh
npm run license -- --edition pro --id EMC-000001 --expires never
```

**Lab**-лицензия до указанной даты:

```sh
npm run license -- --edition lab --id EMC-LAB-0001 --expires 2027-12-31
```

Редакция `personal` также доступна для legacy-лицензий. Community-лицензии не выпускаются.

По умолчанию утилита читает `private-key.pem` из корня проекта. Более безопасно держать ключ вне рабочей копии и передавать путь явно:

```sh
npm run license -- --private-key /secure/path/private-key.pem --edition pro --id EMC-000002
```

Вместо флага можно задать переменную `EMC_LICENSE_PRIVATE_KEY`. Результирующую строку лицензии можно передать пользователю; private key передавать нельзя.

## Проверка

```sh
npm test
```

Тесты проверяют существующий формат payload/signature, все поддерживаемые редакции, значения по умолчанию и корректность Ed25519 public key.
